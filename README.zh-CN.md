# 保养指南小程序

[English](README.md) | [简体中文](README.zh-CN.md)

保养指南是一个原生微信小程序，用来帮助车主理解常规保养周期、记录车辆保养信息，并减少不必要的保养消费。项目采用端上规则引擎，所有车辆数据都保存在微信本地存储中，无需后端服务即可运行。

## 功能特性

- 创建车辆档案，记录车型、里程和用车环境
- 根据内置规则集生成保养体检清单
- 查看单项保养状态、判断依据和参考说明
- 本地记录保养历史和花费
- 浏览常见保养项目的避坑文章
- 无需服务器、云函数或数据库

## 技术栈

- 微信小程序原生框架
- JavaScript
- WXML
- WXSS
- 微信本地存储 `wx.storage`
- 端上规则引擎 `utils/engine.js`

## 快速开始

1. 安装并打开微信开发者工具。
2. 导入本仓库作为小程序项目。
3. 本地开发可使用 `touristappid`；正式上传前，请将 `project.config.json` 中的 `appid` 替换为你自己的小程序 AppID。
4. 在微信开发者工具中点击编译。
5. 在模拟器或真机中预览小程序。
